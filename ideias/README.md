# Ideias — PartyRank

Pasta para registrar ideias de produto, marca e features antes de virarem código.
Cada ideia é um arquivo numerado. Ordem do número = ordem em que foi anotada, não prioridade.

## Status possíveis
- `rascunho` — ainda discutindo
- `aprovada` — vai ser feita, falta priorizar
- `em-execucao` — sendo construída agora
- `feita` — entregue
- `descartada` — analisada e rejeitada (mantém o registro do porquê)
